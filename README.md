# ResearchMate AI 📚

Advanced AI-powered research paper analyzer built using Python and Streamlit.

## Features

- PDF Upload
- Automatic Summarization
- Keyword Extraction
- Research Objective Detection
- Limitation Detection
- Quiz Generation
- Interactive Charts
- Paper Statistics Dashboard

## Technologies

- Python
- Streamlit
- PyMuPDF
- Sumy
- Scikit-Learn
- Plotly
- Pandas

## Run

```bash
streamlit run app.py
```
